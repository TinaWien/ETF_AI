collect_stock_data.py 실행 프롬프트

목적: 국내 상장 전체 주식(코스피+코스닥) 종목의 메타데이터(17개 컬럼)를 수집하여 스타일이 적용된 엑셀 파일로 저장
입력: 없음 (CLI 인자 없음, 네이버 금융에서 전체 종목 자동 수집)
출력: ./output/Stock_YYYYMMDD.xlsx (단일 시트 "국내주식 종목현황", 17개 컬럼, 시가총액 내림차순)

실행: python collect_stock_data.py

수집 컬럼 (17개):
  종목코드, 종목명, 유형, KRX업종, WICS업종, 현재가,
  시가총액(억), 외국인비율, 투자의견, 목표주가,
  52주최고, 52주최저, PER, PBR, 배당수익률, 배당금, 관리종목

데이터 소스:
  - 네이버 시가총액 페이지 → 기본 정보 (종목코드, 종목명, 시장, 현재가, 시가총액, 외국인비율)
  - 네이버 배당 리스트 → 배당금
  - 네이버 관리/경고 페이지 → 관리종목/거래정지/투자주의/경고/위험
  - KOSPI 200 / KOSDAQ 150 구성종목 → 유형 분류
  - Naver Mobile API → 투자의견, 목표주가, 52주 가격, PER, PBR, 배당수익률
  - WiseFN → KRX 업종 (시장분류 기준) 및 WICS 업종 (WICS 기준)

유형 분류: 코스피200 / 코스피 / 코스닥150 / 코스닥
병렬 처리: ThreadPoolExecutor (기본 정보 max_workers=15, 상세 지표 max_workers=20)
429 재시도: 최대 3회, 지수 백오프
엑셀 스타일: Malgun Gothic, 헤더 배경색, 테두리, 열 너비 자동 조정

의존성: requests, beautifulsoup4, pandas, openpyxl, tqdm
