collect_etf_data.py 실행 프롬프트

목적: 국내 상장 전체 ETF 종목의 메타데이터(18개 컬럼)를 수집하여 스타일이 적용된 엑셀 파일로 저장
입력: 없음 (CLI 인자 없음, 네이버 금융 API에서 자동으로 전체 ETF 목록 조회)
출력: ./output/ETF_YYYYMMDD.xlsx (단일 시트, 18개 컬럼)

실행: python collect_etf_data.py

수집 컬럼 (18개):
  종목코드, 종목명, 자산운용사, 대분류유형, 중분류유형, 소분류유형,
  기초지수명, 상장일, 시가총액(억원), 거래량, 수수료,
  지급기준일, 최근분배금(원),
  수익률(3개월), 수익률(6개월), 수익률(12개월),
  52주최고, 52주최저

데이터 소스:
  - 네이버 금융 API → ETF 목록 (종목코드, 종목명, 시가총액, 거래량, 탭코드)
  - WiseFN (companyinfo.stock.naver.com) → 상세 정보 (기초지수, 상장일, 보수, 운용사, 52주 가격, 수익률, 지급기준일)
  - Yahoo Finance (yfinance) → 최근 분배금

병렬 처리: ThreadPoolExecutor, max_workers=15
분류 체계: etfTabCode 기반 대/중/소 분류 자동 매핑
엑셀 스타일: Malgun Gothic, 헤더 배경색, 테두리, 오토필터, 열 너비 자동 조정

의존성: requests, pandas, openpyxl, tqdm, yfinance
