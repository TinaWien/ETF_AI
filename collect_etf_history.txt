collect_etf_history.py 실행 프롬프트

목적: 국내 상장 ETF의 과거 시세(OHLC)를 수집하여 6개 CSV 파일로 저장
입력: CLI 인자 (--code, --start, --end) 또는 전체 ETF 자동 조회
출력: ./output/ 디렉터리에 6개 CSV 파일 생성
  - ETF_actual_daily_YYYYMMDD.csv
  - ETF_adjusted_daily_YYYYMMDD.csv
  - ETF_actual_weekly_YYYYMMDD.csv
  - ETF_adjusted_weekly_YYYYMMDD.csv
  - ETF_actual_monthly_YYYYMMDD.csv
  - ETF_adjusted_monthly_YYYYMMDD.csv

실행: python collect_etf_history.py
      python collect_etf_history.py --code 069500,360750
      python collect_etf_history.py --start 20230101 --end 20231231

주요옵션:
  --code   특정 ETF 종목코드 (쉼표 구분, 미지정 시 전체 ETF)
  --start  시작 날짜 YYYYMMDD (기본값: 1년 전)
  --end    종료 날짜 YYYYMMDD (기본값: 오늘)

CSV 컬럼 (7개): 날짜, 종목코드, 시가, 고가, 저가, 종가, 출처
인코딩: utf-8-sig
정렬: 날짜, 종목코드 오름차순

데이터 소스 (3단계 폴백):
  1. Naver Mobile API (m.stock.naver.com)
  2. KRX (pykrx)
  3. Yahoo Finance (yfinance)

병렬 처리: ThreadPoolExecutor, max_workers=20
데이터 정제: 0원 가격 보정, 고가<저가 보정, 정수 변환

의존성: requests, pandas, tqdm, yfinance, pykrx
